# tokaDisplay 多語系說明

使用共用套件 tokaI18n 0.1.0（內嵌進 jar，重定位到 `dev.toka.display.internal.i18n`）。目前只有繁體中文 `zh-TW`，語言由 config.yml 的 `language` 決定。

## 統計

已抽出 31 個 key，檔案在 `src/main/resources/lang/zh-TW.yml`。

| 區 | 數量 | 內容 |
|---|---|---|
| `cmd.display.*` | 6 | 總用法、list／unpin／clear／testbar 用法、motd／broadcast 用法 |
| `help.display` | 1 | `/display help` 多行說明（第一行標題） |
| `msg.display.*`、`msg.announce.*` | 8 | 狀態、列表一列與總數、移除、清除、測試血條（血條文字與回覆）、公告已儲存 |
| `err.*` | 5 | 找不到玩家、只能在遊戲內、填充度範圍、沒有管理權限、公告操作失敗 |
| `log.*` | 6 | 載入 MOTD／廣播數、預設顏色錯誤、血條顏色錯誤、玩家顯示暫停、公告儲存關閉失敗 |
| `status.*` | 5 | 預設顏色、固定、單次、永久、剩餘秒數 |

## 每個指令的 help 位置

- `/display help`：`help.display`（列出所有子指令與參數，含 motd／broadcast）。僅 `tokaDisplay.admin` 可用，與其他子指令一致。
- `/display`（無參數）：`msg.display.status` 加上 `cmd.display.usage`（行為與原本相同）。
- 各子指令用法錯誤時：`cmd.display.<unpin|clear|testbar>.usage`、`cmd.display.announce.usage`。

## 顏色套用對照

| 文字 | 套用 |
|---|---|
| 一般回覆 | `§b` 主文字，數字／名稱 `§a` |
| 成功（移除、清除、已儲存、測試血條已啟動） | `§a` |
| 錯誤（找不到玩家、填充度、權限、操作未完成） | `§c` |
| 用法 | `§7` |
| 後台 log | 不加方括號標籤；一般 `§b` 數字 `§a`；警告 `§e` |
| help | 標題 `§6§l`、指令 `§e`、符號 `§7`、說明 `§b` |
| 血條上的測試文字 | 維持原本的 `§e` |

## 沒有抽出的項目

- `messages.flash-prefix`、`messages.pinned-prefix` 是 config 值，維持在 config.yml。
- `Layout` 是純邏輯，內部沒有文字。
- 例外（Exception）訊息給開發者看，保留英文。
- 指令名、權限節點、config key、公開 API 方法名不翻譯。plugin.yml 的 description／usage 已是繁體中文，但那是 Nukkit 讀取的靜態欄位，不走語系檔。

## 待確認

1. 原本 `/display list` 的每一列、`unpin`、`clear` 等回覆沒有顏色，現在依慣例加上色碼（顏色套用屬於允許的行為變更）；列表一列的欄位配色是自行判斷，請確認。
2. `/display help` 放在 `tokaDisplay.admin` 權限內（與其他子指令一致）；一般玩家只會看到沒有回應。是否要開放給 `tokaDisplay.use`？
3. `/display testbar` 在血條上的測試文字原本就是 `§e`（警告色），慣例沒有涵蓋「血條上的文字」，維持原色。
4. 慣例沒有規定 help 中「參數說明」的格式；`/display motd`、`broadcast` 的子指令各列一行，broadcast 合併成一行。
5. plugin.yml 的 `description`／`usage` 無法使用語系檔，若之後要支援 en-US 需另外處理。
6. 列表訊息內容截斷時使用的省略號 `…`（`…`）不是中文也沒有放進語系檔。
7. `msg.announce.saved` 的 `${0}` 直接顯示 `motd`／`broadcast` 指令名稱，未翻譯。
8. `/display motd list` 與 `/display broadcast list` 回傳的是 JSON 字串（API 資料），未改動也未包進語系。
